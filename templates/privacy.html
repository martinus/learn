02

What stays in your browserWas in Ihrem Browser bleibt

If you select a colour mode, a text size or a language, your browser keeps this selection, so the next page looks the same. The selection stays on your device. The site does not send it to a server. You can remove it when you delete the website data of this site in your browser.

Wenn Sie einen Farbmodus, eine Schriftgröße oder eine Sprache wählen, merkt sich Ihr Browser diese Auswahl, damit die nächste Seite gleich aussieht. Die Auswahl bleibt auf Ihrem Gerät. Die Website sendet sie an keinen Server. Sie können sie entfernen, indem Sie in Ihrem Browser die Websitedaten dieser Website löschen.

If you turn on comments and write a comment on a page, your browser keeps the comment on your device. The site does not send it to a server. “Copy prompt” puts the comments on your clipboard. “Open as GitHub issue” opens a page of GitHub with the comments as text. GitHub gets the text only if you send the issue there. The issue is then public, and the rules of GitHub apply.

Wenn Sie Kommentare einschalten und eine Seite kommentieren, speichert Ihr Browser den Kommentar auf Ihrem Gerät. Die Website sendet ihn an keinen Server. „Prompt kopieren“ legt die Kommentare in Ihre Zwischenablage. „Als GitHub-Issue öffnen“ öffnet eine Seite von GitHub mit den Kommentaren als Text. GitHub erhält den Text erst, wenn Sie das Issue dort absenden. Das Issue ist dann öffentlich, und es gelten die Regeln von GitHub.

The charts calculate their data in your browser. What you do with a slider or a button is not recorded.

Die Diagramme berechnen ihre Daten in Ihrem Browser. Was Sie mit einem Regler oder einer Schaltfläche machen, wird nicht aufgezeichnet.

Who delivers the pagesWer die Seiten ausliefert

Two companies from the USA deliver this site: GitHub stores the pages (GitHub Pages), and Cloudflare passes them on to you. To send a page to your device, their servers must know your IP address, as each server on the internet must. They can keep technical records of requests for a limited time, for example to stop attacks. I cannot see these records for a single visitor.

Zwei Unternehmen aus den USA liefern diese Website aus: GitHub speichert die Seiten (GitHub Pages), und Cloudflare leitet sie an Sie weiter. Um eine Seite an Ihr Gerät zu senden, müssen ihre Server Ihre IP-Adresse kennen, so wie jeder Server im Internet. Sie können technische Aufzeichnungen über Anfragen für begrenzte Zeit speichern, zum Beispiel zur Abwehr von Angriffen. Ich kann diese Aufzeichnungen für einzelne Besucher nicht einsehen.

The legal basis is the legitimate interest to operate a website safely (Article 6(1)(f) GDPR). Fonts and scripts of the pages are files of this site. The pages do not load them from other services.

Die Rechtsgrundlage ist das berechtigte Interesse, eine Website sicher zu betreiben (Art. 6 Abs. 1 lit. f DSGVO). Schriften und Skripte der Seiten sind Dateien dieser Website. Die Seiten laden sie nicht von anderen Diensten.

04

How visits are countedWie Besuche gezählt werden

I want to know which pages people read. For this, the site uses Cloudflare Web Analytics. Cloudflare adds a small script to each page. The script reports that a page was opened: which page, from which website the visitor came, the type of browser and device, the country, and how fast the page loaded.

Ich möchte wissen, welche Seiten gelesen werden. Dafür verwendet die Website Cloudflare Web Analytics. Cloudflare fügt jeder Seite ein kleines Skript hinzu. Das Skript meldet, dass eine Seite geöffnet wurde: welche Seite, von welcher Website der Besuch kam, die Art von Browser und Gerät, das Land und wie schnell die Seite geladen wurde.

Cloudflare states that this service uses no cookies, stores nothing in your browser, and does not follow a person from one website to a different one. I see only totals, for example “120 visits to this page from Austria”. I cannot see who a visitor is.

Cloudflare gibt an, dass dieser Dienst keine Cookies verwendet, nichts in Ihrem Browser speichert und Personen nicht von einer Website zur nächsten verfolgt. Ich sehe nur Summen, zum Beispiel „120 Besuche dieser Seite aus Österreich“. Ich kann nicht sehen, wer ein Besucher ist.

If you do not want to be counted, a content blocker in your browser stops the script. The pages work without it.

Wenn Sie nicht gezählt werden möchten, blockiert ein Inhaltsblocker in Ihrem Browser das Skript. Die Seiten funktionieren auch ohne es.
